# 代码动画风格提示词

342 种代码动画风格，每种一个提示词，Opus 5.5 能用，DeepSeek 也能用。其中 194 种带静帧。

**从哪里开始：** 用 Chrome 或 Edge 双击打开 [`风格挑选.html`](风格挑选.html)，不用联网。可以按类别筛、搜索、放大看静帧、看提示词、勾选，最后导出清单。

- 每种风格的提示词全文在 [`风格提示词/`](风格提示词/)，带静帧的旁边有一张同名 `.jpg`
- 两组实测在 [`示例/`](示例/)
- 每一类怎么来的、用什么许可，看 [`许可与来源.md`](许可与来源.md)、[`第三方许可/`](第三方许可/)
- 各项数量见 [`_统计.json`](_统计.json)

完整说明（每种风格怎么用、怎么跟 AI 说）在 [`说明.md`](说明.md)。

> 仓库里没有提交 `示例/` 的成品视频（三个 mp4 共 61MB）。视频在原分享包里，html 和截图都在。
